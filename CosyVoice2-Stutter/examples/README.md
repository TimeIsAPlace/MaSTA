# Retained upstream examples

These LibriTTS, MagicData, CosyVoice3 and GRPO recipes are retained as upstream
reference material. They are not the supported MaSTA stutter workflow, and their
dependencies and published metrics have not been reproduced in this release.
Use [the project README](../README.md) and `recipes/cosyvoice2/` for that workflow.

Flattened source links are materialized as regular files for portable checkout.
Run these legacy recipes from their own recipe directory. Data paths are local
defaults and may be overridden with `DATA_DIR`. GRPO requires its separate
environment; see its README. Preserve all original copyright notices.
