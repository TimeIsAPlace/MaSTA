# MaskGCT 口吃语音合成

这是从研究工程中独立整理的 MaskGCT 分支，仅包含口吃语音的训练、
token 数据构建与合成。原始工程不需要放在旁边，也不会被本仓库修改。

## 三阶段训练

| 阶段 | 数据 | 训练内容 | 初始化 |
| --- | --- | --- | --- |
| 1 | 真实口吃语音及带事件标记的文本 | 整句 T2S 条件建模，学习口吃标记与语音的关系 | 原始 MaskGCT T2S |
| 2 | AISHELL-1 正常语音 | 随机 mask 20%-40% 字符对应的时间区域，训练语义 token 填充 | 阶段 1 的选定权重 |
| 3 | 真实口吃语音 | 按对齐结果 mask 口吃事件区域，训练定向填充 | 阶段 2 的选定权重 |

第一阶段“整句”指训练任务，不是所有帧均计算 loss：原代码仍在采样出的
mask 上计算交叉熵。第二、三阶段使用缓存提供的区域 mask。
三阶段微调的是 T2S；合成时再经 S2A 和 acoustic codec 解码得到语音。
可选的 `train_s2a.py` 不属于以上三阶段。

## 使用顺序

1. 按 [英文 README](README.md) 安装 Python 3.10、依赖和 espeak-ng。
2. 按 [权重说明](docs/ASSETS.md) 放置模型、G2P 资源和语义特征统计量。
3. 准备自己的音频和 TextGrid 对齐结果，按 [数据格式](docs/DATA.md) 构建 train/dev 缓存。
4. 依次运行 `scripts/stage1_t2s.sh`、`stage2_fill_mask.sh`、`stage3_stutter.sh`。
5. 每阶段通过 `--init-checkpoint` 明确传入上一阶段选定的权重。
6. 用 `scripts/synthesize.sh` 和第三阶段权重进行事件区域填充合成。

完整可复制命令见 [README](README.md)。训练脚本支持单机多卡，
通过 `CUDA_VISIBLE_DEVICES` 选择，不要再套一层 torchrun。
训练参数沿用 `MaskGCT/config/train.json`，模型结构在 `config/maskgct.json`。
原有 batch_size=2、梯度累积=8 没有擅自调整；epochs=30000 是原配置，
公开实验应自行明确实际训练轮数/预算，不代表推荐跑满该值。

训练包装脚本的路径相对调用目录；缓存与合成 shell 脚本会先进入 `MaskGCT/`，
因此示例用 `../data/...`。没有硬编码开发者机器上的绝对路径。

## 发布内容与限制

- 包含：三个训练入口、两个推理入口、数据集代码、必要模型/codec/G2P 代码、脚本和示例。
- 不包含：真实音频、私人转录、缓存、预训练权重、训练结果、CosyVoice、ASR 或评分系统。
- 原有模型权重检查点不含优化器状态，不能声称精确断点续训。
- 合成入口依赖已有语义 token 和 mask，不是仅输入任意文本即可直接生成。
- 对齐模型不内置；请提供符合格式的对齐结果。
- 本次整理只做静态和脚本测试，没有重新执行 GPU 训练和合成实验。
